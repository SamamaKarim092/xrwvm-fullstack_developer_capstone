# Dealership & Reviews Fullstack Capstone Application

**Repository Name**: `xrwvm-fullstack_developer_capstone`  
**Project Name**: `Dealership & Reviews Fullstack Capstone Application`

---

## About the Project
This fullstack web application allows users to browse car dealerships across the United States, view customer reviews with automated sentiment analysis, create and manage car makes/models, and post new reviews.

## System Architecture & Technologies Used
- **Frontend**: React, JavaScript (ES6+), HTML5, CSS3, Bootstrap
- **Backend / Proxy Service**: Django (Python 3.10+)
- **Database Backend Service**: Express.js (Node.js) & MongoDB (Mongoose)
- **Sentiment Analyzer Microservice**: Python Flask & NLTK (VADER Sentiment Lexicon)
- **CI/CD Pipeline**: GitHub Actions (`flake8` Python linting & `jshint` JS linting)
- **Containerization & Deployment**: Docker & Kubernetes Deployment Manifests
